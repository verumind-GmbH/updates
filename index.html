Installation

Auf dem vorbereiteten Linux-Server ausführen:

curl -fsSL https://updates.verumind.de/verumind-hub-install.tar.gz | tar -xz -C /opt
cd /opt/verumind-hub && chmod +x install.sh
sudo ./install.sh

Das Skript ermittelt die aktuelle Version selbstständig, erzeugt alle Zugangs­geheimnisse und startet die Anwendung. Abgefragt werden nur Domain, E-Mail-Adressen, Administrator-Passwort und Ihr Registry-Token.

Den vollständigen Ablauf inklusive Voraussetzungen, Inbetriebnahme und Betrieb beschreibt die Installationsanleitung, die Sie von verumind erhalten haben.

Systemvoraussetzungen (Kurzfassung)

  • 64-bit-Linux (aktuelle LTS-Version), Zugang mit root/sudo
  • mindestens 2 CPU-Kerne, 4 GB RAM, 40 GB freier SSD-Speicher
  • Docker Engine 24+ und Docker Compose v2
  • Ports 80 und 443 eingehend erreichbar
  • (Sub-)Domain, deren DNS-Eintrag vor der Installation auf den Server zeigt

Integrität prüfen (empfohlen)

So stellen Sie sicher, dass das heruntergeladene Paket unverfälscht ist:

curl -fsSLO https://updates.verumind.de/verumind-hub-install.tar.gz
curl -fsSLO https://updates.verumind.de/verumind-hub-install.tar.gz.sha256
sha256sum -c verumind-hub-install.tar.gz.sha256

Die Ausgabe muss OK lauten. Weicht sie ab, brechen Sie die Installation ab und wenden sich an den Support.
